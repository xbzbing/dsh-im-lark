## 主要变更

- **首个 stage 占位版**：本版只做两件事——占住 npm 包名、验证发布流水线。插件能力已在真实飞书租户里验收，但还要先走一遍 stage 安装路径，`latest` 留给首个正式版。
- **独立模式提问卡**：单题有选项的提问提醒改成飞书交互卡片——单选/多选都是每项一个勾选框加「提交」（飞书没有单选按钮组，靠文案区分），带「其他」输入，提交后卡片改终态；多题、审批与卡片发失败仍走文字（[ADR-0005](../adr/0005-独立模式问题与审批提醒.md)）。
- **发布流水线**：main 上改到 `package.json` 的提交会自动跑门禁、打 tag、发 npm、建 Release，正文随版本入库（[ADR-0007](../adr/0007-发布流程与版本通道.md)）。
- **内部**：测试不再依赖私有核心 `dsh-my-superagent`——devDependency 已移除，桥一致性契约在 `bridge.test.ts` 里本地重写，公开 CI 与本地跑的是同一套。

## English

- **First stage placeholder**: this version only reserves the npm package name and exercises the release pipeline. Capabilities have been accepted against a real Feishu tenant, but the stage install path still needs one pass; `latest` waits for the first stable release.
- **Standalone question cards**: a single-question reminder with options now renders as a Feishu interactive card — one checkbox per option plus a submit button for both single- and multi-select (Feishu has no radio group, so the text says which is which), an "other" input, patched to a terminal state after answering; multi-question, approvals and card failures still fall back to text ([ADR-0005](../adr/0005-独立模式问题与审批提醒.md)).
- **Release pipeline**: a commit touching `package.json` on main runs the gate, tags, publishes to npm and opens a Release; the body ships in the repository ([ADR-0007](../adr/0007-发布流程与版本通道.md)).
- **Internal**: tests no longer depend on the private core `dsh-my-superagent` — the devDependency is gone and the bridge conformance contract is rewritten locally in `bridge.test.ts`, so public CI runs exactly the same suite as local.
