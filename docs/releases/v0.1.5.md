## 主要变更

- **按会话投递**：新增 `/sessions` 与 `/send <序号、0 或会话 id> <内容>`。`/sessions` 列出最近会话并给出稳定序号；`/send` 把消息发到指定会话，那一轮的回答回到当前聊天，`/send 0` 直接发到前台会话。提交走排队，不打断目标会话正在跑的回合，附图照常支持。
- **切换会话**：新增 `/switch <序号、0、front 或会话 id>`。切到非前台会话后，回复带 `**会话名>**` 前缀；`/switch 0` 或 `/switch front` 回到最初的前台会话，前缀随之消失。换绑与前缀跨重启保留，`/new` 清除；目标还有 `/send` 在等回答时拒绝切换。
- **修复**：前台会话被删除、旧版 `direct.json` 缺前台记录时，`/switch 0` 与 `/send 0` 统一提示用 `/new` 重建，不再让人空等；`/switch` 与标题事件并发时不再用旧快照覆盖新标题；`/sessions` 不列前台，避免回到前台后列表里再套一个自己。
- **内部**：`/sessions`、`/send`、`/switch` 拆成独立编排模块；`direct.json` 的写入改为串行读改写，首次读盘 single-flight，临时文件名加随机后缀，停机时排空写入队列。

## English

- **Per-session delivery**: added `/sessions` and `/send <index, 0, or session id> <text>`. `/sessions` lists recent sessions with stable indices; `/send` delivers to the chosen session and routes that round's answer back to the current chat, with `/send 0` targeting the front session. Submissions are queued, so the target's running turn is not interrupted; images are still supported.
- **Session switching**: added `/switch <index, 0, front, or session id>`. After switching to a non-front session, replies are prefixed with `**session name>**`; `/switch 0` or `/switch front` returns to the original front session and drops the prefix. The binding and prefix survive restarts and are cleared by `/new`; switching is refused while the target still has a `/send` waiting for its answer.
- **Fixes**: when the front session was deleted, or an older `direct.json` has no front-session record, `/switch 0` and `/send 0` now point to `/new` instead of leaving the user waiting; concurrent title events and `/switch` no longer overwrite a newer title with a stale snapshot; `/sessions` omits the front session, so returning to it does not produce a self-referential list.
- **Internal**: `/sessions`, `/send`, and `/switch` now live in separate orchestration modules; `direct.json` writes use a serialized read-modify-write queue, first load is single-flight, temp file names carry a random suffix, and pending writes are drained on shutdown.
