## 主要变更

- **「回合内插话」覆盖所有发送**：普通消息与 `/send`（发到当前会话或其它会话）在目标回合正在跑时，都按面板设置决定插进当前回合还是排队。此前 `/send` 跨会话固定排队，开关只管发到当前会话那条；现在一个设置管全部，面板提示也写清了范围。
- **新增 `/queue`**：参数与 `/send` 完全相同（序号、`0`、`front`、会话 id、附图），但始终排队到目标当前回合之后，不受「回合内插话」影响。需要明确不打断目标时用它。
- **修复**：排队消息在目标已有别人一轮在跑时，不再跟着那一轮的 `turn/end` 提前打 `DONE`；跨会话投递也不再靠 `/sessions` 快照判断目标是否在跑，快照过期时不会把别人的回答当成自己的。
- **内部**：`DoneAlign` 增加「排在这一轮之后」标记并按它跳过别人的一轮；`/send` 与 `/queue` 共用定位、图片与回答回收，只差提交模式；ADR-0011 记录取舍与两条已知限制。

## English

- **The steer setting now covers every send**: regular messages and `/send` (to the current session or any other) all follow the panel setting when the target is mid-turn — join the running turn or queue behind it. Previously `/send` to another session always queued and the switch only affected messages to the current session; one setting now governs all of them, and the panel text spells out the scope.
- **New `/queue`**: takes exactly the same arguments as `/send` (index, `0`, `front`, session id, images) but always queues behind the target's current turn, ignoring the steer setting. Use it when the target must not be interrupted.
- **Fixes**: a queued message no longer gets its `DONE` from someone else's turn ending while the target was already running; cross-session delivery no longer relies on the `/sessions` snapshot to tell whether the target is running, so a stale snapshot cannot return another turn's answer as its own.
- **Internal**: `DoneAlign` marks entries that sit behind a running turn and skips that turn; `/send` and `/queue` share session lookup, images and answer collection, differing only in submit mode; ADR-0011 records the trade-offs and two known limits.
