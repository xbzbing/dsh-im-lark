## 主要变更

- **面板信息更完整**：连接状态卡片不再重复显示「长连接」（状态胶囊只在卡片头部出现一次），App ID 改为**完整显示**，已绑定时还会预填进「应用凭据」的输入框——改 Secret 不用重输一遍。
- **凭据卡片显示绑定时间**：标题下方第二行给出「绑定于 YYYY-MM-DD HH:mm:ss」。时间跟着 App ID 走：同一个应用重复保存保留首次时间，换 App ID 才重置；本版之前保存的凭据没有时间戳，用凭据文件的修改时间兜底（只在内存补，不写盘）。
- **内部**：脱敏口径写进 AGENTS.md、README 与方案设计——日志与错误信息仍只出现 App ID 尾号，面板可以显示完整 App ID（App ID 不是密钥），App Secret 永不出现在任何地方。

## English

- **Richer panel status**: the connection card no longer repeats the "Long connection" row (the status pill already sits in the card header); the App ID is now shown **in full** and prefilled into the credentials input once bound, so changing the Secret does not mean retyping it.
- **Bound time on the credentials card**: a second line under the title reads "Bound since YYYY-MM-DD HH:mm:ss". The time follows the App ID — re-saving the same app keeps the first timestamp, only a new App ID resets it; credentials saved before this version have no timestamp, so the credentials file's mtime stands in (filled in memory only, never written back).
- **Internal**: the redaction policy is now spelled out in AGENTS.md, README and the design doc — logs and error messages still carry only the last six digits of the App ID, the panel may show the full App ID (it is not a secret), and the App Secret never appears anywhere.
